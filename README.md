# 火车突突突｜钢铁巨龙

一个无需构建工具的浏览器 3D 火车驾驶小游戏。玩家可以驾驶列车沿环形轨道行驶，控制牵引与制动、观察限速提示、切换摄像机视角和昼夜，并使用鸣笛。

> 本项目是娱乐用途的简化模拟，不代表真实列车的操作规程或安全系统。

## 快速开始

将仓库克隆或下载到本地后，直接在现代浏览器中打开 `index.html` 即可。项目通过 CDN 加载 Three.js，因此首次运行需要联网。

如果浏览器限制本地文件加载，可以在项目目录启动一个静态 HTTP 服务，例如：

```bash
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。

## 操作说明

| 操作 | 键盘 | 手机触控 |
| --- | --- | --- |
| 增加牵引 / 加速 | `W` 或 `↑` | 加速 |
| 减少牵引；牵引为零时逐步制动 | `S` 或 `↓` | 刹车 |
| 紧急制动 | `空格` | — |
| 切换摄像机视角 | `C` | 视角 |
| 鸣笛 | `H` | 鸣笛 |
| 切换昼夜 | `N` | — |

游戏设有三种视角：驾驶室、追尾和无人机视角。速度超过当前限速并持续一段时间会触发脱轨提示；点击重新开始即可重置游戏。

## 技术与依赖

项目采用原生 HTML、CSS 和 JavaScript，并使用 [Three.js](https://threejs.org/) 进行 WebGL 3D 渲染。当前页面从 cdnjs 加载 Three.js `0.160.0`：

```html
<script src="https://cdnjs.cloudflare.com/ajax/libs/three.js/0.160.0/three.min.js"></script>
```

场景中的列车、轨道、车站、树木、信号灯和音效均由代码生成，不需要额外的模型或音频文件。
